# Generic templates

These files are placeholders, not commands or active configuration. Replace placeholder values only after checking the target's current authority, repository policy, and capabilities. They are portable procedure and do not grant credentials, deployment permission, state transitions, or other authority.

- [Contract body template](contract-template.md) is the canonical editable source for a specific contract's `body_markdown` authoring convention.
- [Issue work contract](issue-work-contract.md) remains the generic tracker/work-record template; it is not a competing canonical contract-body source.
- [Implementation card](implementation-card.md) remains the separate execution-card template; it is not a contract-body template.
- [Completion receipt](completion-receipt.md)
- [Continuation marker/config](continuation-marker-config.md)
- [Secret-safe environment example](environment.example)
