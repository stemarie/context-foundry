# Foundry Implement

Read [Worker](../foundry-worker/SKILL.md), the [native interface](../foundry-shared/skills/AI_CONTRACT_INTERFACE.md) and [operating rules](../foundry-shared/skills/OPERATING_RULES.md). Resolve the project/contract from the request and current service state. An old issue number alone supplies no native attempt or permission to execute.

Require an actor-bound assignment, supported runtime/workspace adapter and current semantic version plus complete native executable revision. Coordinator reserves/launches; this skill does not self-claim or fabricate those prerequisites. Verify repository identity, base, branch, applicable AGENTS.md, current revision/digest/attempt and scope before changing files. Preserve intervening/unrelated work.

Trace reported defects to actionable implementation/configuration/runtime causes. Implement only the authorized outcome, run meaningful required checks and inspect the candidate diff. Label hypotheses, failures and skipped checks accurately. Routine recoverable setup problems stay within the existing repair policy; material requirement conflicts return to Architect through Coordinator.

Submit an immutable local candidate through `workflow_submit` with actual check evidence and current bindings. Reconcile uncertain submission using the durable prepared intent/SHA; never create an empty second commit or infer acceptance from a local receipt. Stay assigned through QA corrections and require fresh QA for changed candidates.

Do not self-approve, integrate, mark Done, publish historical issues or deploy. Return the service candidate/attempt/revision, verification evidence and actual stage. OpenSpec checkboxes describe demonstrated work; they do not replace native ownership or completion.
